① 一句话理解

把一次回答想象成工厂流水线：
  • 大模型（LLM） = 源头的水龙头，一边生成一边滴水。
  • Agent 层 = 搬水工，开一个传送带（channel），边接水边往上传。
  • Server 层 = 你家的水龙头，在传送带另一头接水、立刻显示。
这次重构，就是给"搬水工"配了一条传送带——它和生产、消费两件事解耦，所以能"一边生成、一边显示"。

⑤ 为什么用 goroutine + channel，而不是纯回调？

对比点旧做法（纯回调）新做法（goroutine + channel）
解耦onDelta 直接打到 UI生产(跑循环)与消费(刷UI)解耦，可"边生成边显示"
响应时机要等整条链路跑起来才显示Stream 立刻返回 channel，马上能收事件
取消得层层 return 退出关掉 channel，for range 自然结束，干净收尾
模式一致—与项目里 watcher.Subscribe() 返回 channel 的模式统一

一句话：channel 就是那条传送带，把"模型慢慢吐字"和"浏览器慢慢显示"这两件事拆开。
