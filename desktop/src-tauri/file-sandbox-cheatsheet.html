三个「主动说出来」的细节 加分点
  • 为什么新建文件要退到父目录解析？EvalSymlinks 需要目标存在；用 Lstat（不跟随链接）判断存在性，不存在则向上退到最近已存在祖先 → 写 link_outside/new.txt 也能拦下。
  • EvalSymlinks 失败会被静默跳过：`if evalErr == nil` 才做检查。父目录不存在（新建）可接受，但权限/系统错误也会跳过 → 安全隐患，生产应区分 os.IsNotExist 与其他错误。
  • Agent 写用户文件本身不是原子的：write_file 用普通 WriteFile（tools.go:260）；「原子写入」只保障沙箱自己的状态文件（undo.json / workspaces.json / MCP 配置），因为 undo 链一旦损坏整个恢复体系就断了。

EvalSymlinks 检查存在 TOCTOU 竞态，怎么破？

          
点击翻转 ▸

        
参考答案

    •
